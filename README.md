# SCRUMManager

Este repositorio contiene el prototipo funcional de la herramienta de gestión Scrum para el Sprint 0, desarrollado como entregable de la materia.

## Equipo de Desarrollo (Frente D)
- **Osmar** (Diseño de tableros, flujos de trabajo y métricas)
- **Emanuel** (Evaluación de herramientas y configuración del entorno)
- **Franks** (Documentación técnica y validación)

## Funcionalidades del Prototipo
1. **Product Backlog:** Lista priorizada usando la técnica MoSCoW (Etiquetas de color).
2. **Tablero Kanban Interactivo:** Columnas *Por hacer, En progreso, En revisión, Terminado*. Implementado con funcionalidad Drag & Drop.
3. **Métricas Visuales:** Placeholder para la gráfica Burndown Chart integrando los Puntos de Historia.

## Tecnologías
- HTML5
- CSS3 (Flexbox)
- Vanilla JavaScript (Drag and Drop API)
